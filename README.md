# functional-programming-java

Repositório criado com o objetivo de treinar **expressões lambda** e **programação funcional** em **Java 8**. Durante os estudos, explorei os principais conceitos da programação funcional aplicados à linguagem Java, utilizando exemplos práticos e exercícios.

## 🔍 Conteúdo Abordado

O projeto está organizado em pacotes, de acordo com os temas estudados:

- `criando.streams`: Introdução à criação e manipulação de *Streams*.
- `interfaces.funcionais`: Uso e criação de interfaces funcionais.
- `introducao.programacao.funcional`: Conceitos iniciais da programação funcional.
- `lambda.fundamentos`: Fundamentos das expressões lambda.
- `method.reference`: Referência a métodos e construtores.
- `novos.metodos.collection`: Métodos funcionais introduzidos nas collections.
- `optional.valores.opcionais`: Trabalhando com a classe `Optional`.
- `refatorando.loops.streams`: Refatoração de loops utilizando streams.
- `streams`: Exercícios variados com a API de Streams.

## 💻 Tecnologias Utilizadas

- **Java 8**
- **IntelliJ IDEA** (como IDE)
- **Paradigma Funcional**
- **Streams API**
- **Expressões Lambda**
- **Optional**
- **Interfaces Funcionais**

## 🧠 Objetivo

Este repositório foi parte da minha jornada de estudos para dominar conceitos da **programação funcional em Java**, com foco em:

- Redução de boilerplate com expressões lambda
